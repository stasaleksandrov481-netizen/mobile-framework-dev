## 2026-11-20 UTC · Android: OTA-интерфейс, файловые операции, подтверждения ИИ-действий

- База: опубликованная `v1.0.18-beta.10`, versionCode 127, `main` `d47d212`. Ветка `fix/cortex-webview-ota-native-pin-20261120`, draft PR #100. Версия не поднималась, APK не публикуется.
- OTA WebView: скачанный пакет интерфейса привязан к versionCode APK, под которым активирован; после обновления/переустановки APK используется встроенный, проверенный в CI интерфейс, повторно ставится только строго более новый подписанный пакет. Устаревшие пакеты и брошенные `staging-*` удаляются.
- Фото, импорт/экспорт сценариев и экспорт чатов выполняются вне главного потока (риск ANR на облачных провайдерах и больших фото). Экспорт чатов больше не сообщает об успехе, если провайдер не выдал поток записи.
- ИИ-управление экраном: звонок, принятие условий/вызова, выход из аккаунта, отписка и форматирование теперь всегда требуют подтверждения.
- Ответы ИИ: ссылки кликабельны только для HTTPS (Android открывает только HTTPS; http-ссылка раньше всегда давала ошибку).
- Голосовая/текстовая команда яркости больше не отказывает на прошивках, где `screen_brightness` хранится в диапазоне 0..1023/2047/4095 (часть Xiaomi, vivo, Samsung): используется системный максимум или диапазон, выведенный из текущего значения; результат по-прежнему подтверждается чтением настройки. Физическая проверка на этих устройствах не выполнялась.
- Разные оболочки Android: системные приложения («открой галерею/контакты/сообщения/часы/файлы/календарь/почту/карты/музыку/браузер/калькулятор/настройки») открываются по стандартным ролям Android, а не по подписи иконки производителя и падежу. В «Доступах Android» добавлена строка «Работа в фоне»: системное исключение из оптимизации батареи и, если есть на телефоне, экран автозапуска Xiaomi/vivo/OPPO/realme/OnePlus/Huawei/HONOR/Samsung. Добавлены пакеты калькулятора OnePlus, Transsion, Meizu. Ручная матрица — `docs/ANDROID_TEST_MATRIX.md`; на устройствах не проверено.
- Шестизначный код: вставка текста письма («Код действует 10 минут: 482913») даёт именно код, а не первые шесть цифр фразы; подтверждение почты отправляется автоматически после шестой цифры (ввод, вставка, автозаполнение Android); после отказа код выделяется для замены, а сообщение говорит о неверном/устаревшем коде вместо «проверьте пароль». Сервер и ответы API не менялись.
- Напоминания: на Android 13+ точные будильники разрешены сразу после установки (`USE_EXACT_ALARM`), поэтому «напомни в 7:30» больше не сдвигается на Android 14/15 до ручного включения в настройках. Время «7.30» и «19-05» распознаётся как 7:30 и 19:05, а не 7:00 с «.30» в тексте; «через пару минут» — две минуты. На устройствах не проверено.
- Сообщения в Telegram и мессенджерах: «напиши Игорю» находит контакт «Игорь», «напиши Марии» — «Мария». Раньше такие имена не находились, и отправка останавливалась. Похожие имена (Марина, Игорёк) по-прежнему не принимаются, при двух равных совпадениях сообщение не отправляется.
- Голосовые ответы: на время ответа CORTEX приглушает музыку и подкасты (системный аудиофокус) и возвращает громкость после ответа. Раньше голос звучал поверх музыки на полной громкости. На устройствах не проверено.
- Ответы ИИ (Markdown уровня ChatGPT): подсветка кода, формулы LaTeX (через MathML, без сторонних библиотек), графики (столбцы, линии, кольцо), карточка-сводка, схема процесса, сворачиваемые разделы, цветные бейджи, выделение и подчёркивание, восемь видов выносок. Всё строится из проверенных данных: модель не может вставить HTML или скрипт. ИИ получает краткую памятку по этим блокам.
- Интерфейс приложения: единая дизайн-система (`ui.css`) — сгруппированные карточки списков, один масштаб заголовков, иконки в плитках, монохромные переключатели, лёгкие кнопки «Настроить» с цветным статусом разрешения, новая нижняя панель и спокойный экран загрузки. Логика экранов не менялась. Проверено скриншотами в браузере, на телефоне не проверено.
- Чат: новый пустой экран (приветствие, быстрые подсказки, выбор модели в шапке), поле ввода без выбора модели, отдельная страница «Модель» с логотипами компаний, сгруппированными по бесплатным и по производителю. Остаток лимитов убран из профиля и подписки — теперь только кружок под полем ввода, по нажатию окно с процентом, остатком, тарифом и временем обновления.
- Приватность: CORTEX больше не отправляет в Google адреса сайтов из ответов ради значков (раньше каждый домен из чата запрашивался через google.com/s2/favicons). Логотипы моделей встроены в приложение.
- Защита служебных инструкций: модель получает явный запрет пересказывать их в любой форме (код, перевод, ролевая игра, «режим отладки»). Если ответ всё же содержит дословные фрагменты инструкций, приложение заменяет его отказом, в том числе во время печати ответа. Серверная часть правила записана в код, но на сервер ещё не выкачена.
- Голос: CORTEX всегда говорит одним мужским голосом (Gemini Charon) вместо женского по умолчанию и разных голосов у разных аккаунтов — серверная часть записана в код, но на сервер ещё не выкачена. Если облако недоступно, системный голос Android выбирается мужским русским, когда телефон его предоставляет.
- Вызов словом «Кортекс»: слово распознаётся независимо от заглавной буквы (раньше итоговый результат «Кортекс, …» с заглавной мог не сработать) и в частых искажениях («кортес», «картэкс», «кор текс», «Cortex», «алло, кортекса»). На Android 11 и старше вызов по слову не работает: офлайн-распознавание есть только с Android 12, и CORTEX теперь прямо об этом сообщает.
- Синтез речи (полный буфер) передаёт идентификатор устройства только при подтверждённой подписи релизного APK, как и остальные запросы.
- Проверки: JVM-тесты новых правил, JS QA 66/66 локально. CI, эмулятор и физические устройства — по результатам PR; сценарий обновления APK поверх активного OTA вручную не проверялся.
