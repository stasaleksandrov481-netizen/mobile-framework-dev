# CORTEX — публичные передачи между разработчиками

Этот файл содержит только проверяемые неперсональные технические сведения.
Секреты, адреса тестеров, внутренние сессии и закрытые операционные журналы здесь не публикуются.

## 2026-11-19 UTC · Дополнительное укрепление публичного сайта

- В той же целевой ветке `fix/cortex-browser-style-fallback-20261119` добавлена базовая без-CSS вёрстка информационных страниц и тарифов; Playwright теперь проверяет `/questions`, `/support`, `/privacy`, `/pricing` вместе с регистрацией и главной.
- Публичная страница вопросов больше не содержит ссылку на исходный Git-репозиторий. Кнопка установки принимает только прямые HTTPS-ссылки на `.apk` в разрешённых источниках; ссылки на страницы GitHub Releases, другие домены и URL с параметрами отклоняются. Автоматические проверки закреплены в `hardening.test.mjs` и workflow сайта.
- Локальная проверка: TypeScript lint, production Next.js build и 10/10 hardening tests успешны. Публикация в production не выполнялась: одобренный исходник активного сайта по-прежнему не полностью синхронизирован с Git, поэтому его нельзя безопасно заменять.
- Проверка конфигурации: внешний сервер Android-авторизации на этот момент возвращает `email_auth: false`; настройка переменной только в Vercel не управляет окружением Supabase Edge. Нельзя объявлять почтовую регистрацию готовой до серверного включения и E2E-теста доставки.

## 2026-11-19 UTC · Восстановление оформления в мобильных браузерах

- Сообщён случай: публичная страница регистрации в мобильном браузере отрисовалась как HTML без CSS. `cortexapp.ru/register` и её опубликованный `_next/static/*.css` отвечают HTTP 200, основной CSS содержит стили регистрации; WAF не содержит правила, перекрывающего статические ресурсы. Причина отказа на конкретном устройстве пока не установлена.
- Ветка `fix/cortex-browser-style-fallback-20261119` от `main` `d47d212`: серверный минимальный CSS для доступности страниц и формы при отказе внешнего CSS, без изменения штатного дизайна и механики авторизации. Добавлен браузерный регрессионный тест, искусственно блокирующий CSS на мобильных и широких экранах.
- Проверки: TypeScript lint и `next build` успешны; собранный SSR HTML содержит критический `<style>`. Полный Playwright-тест должен пройти на GitHub Actions; локальный Chromium в рабочем окружении не запустился из-за ограничения сокета, это **не** результат теста интерфейса.
- Важно: публичный `cortexapp.ru` сейчас закреплён за одобренным deployment `dpl_AdZ76xMyr3Z7PJMETG31yCUYqgKj`; его исходники не полностью присутствуют в текущем Git `main`. Поэтому изменения этой ветки **нельзя** выпускать на production поверх текущего сайта, пока не восстановлен точный approved frontend source и не проверен визуальный diff. Android, Supabase Edge/DB, платежи и live Vercel deployment не менялись.
- Следующий шаг: проверить CI, восстановить исходники активного сайта из полного экспорта deployment, перенести минимальный fallback поверх них, проверить мобильные и desktop браузеры и только после одобрения выпускать отдельный production deployment.
