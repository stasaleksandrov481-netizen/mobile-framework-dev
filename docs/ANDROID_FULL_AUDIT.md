## Исходное состояние

- `main` `d47d212` = опубликованная `v1.0.18-beta.10`, versionCode 127; CI Android и Security Scan на этом SHA — success.

## Проверено и признано корректным (по коду)

- WebView: `allowFileAccess/ContentAccess=false`, `blockNetworkLoads`, `MIXED_CONTENT_NEVER_ALLOW`, навигация только по asset-хосту, мосты через `addWebMessageListener` с allowlist origin и проверкой main frame, отладка WebView только в debug.
- OTA: подпись манифеста RSA, SHA-256 и размер архива, без редиректов, ограничения распаковки и путей, атомарная активация, откат при сбое рендерера.
- Manifest: `allowBackup=false`, cleartext запрещён; экспортированы только launcher/ASSIST activity и сервисы с системными permission.
- `open-link` фильтруется `CortexSafeUrl`; импорт сценариев ограничен по размеру и структуре.
- Нативный шлюз ИИ (`CortexServerBridge`): ограниченная очередь (3 потока / 16), отмена с разрывом соединения, SSE с лимитами строк/событий/объёма, частичный поток не авторизует выполнение плана, токен в Android Keystore (AES-GCM), отложенный отзыв сессии при выходе офлайн.
- Markdown: `html:false`, ссылки через allowlist, компоненты `cortex-metrics/cards/steps` строго типизированы и экранированы; стрим перерисовывается с троттлингом.
- Голосовой вывод (`CortexVoiceOutput`): жетон поколения отменяет устаревшие PCM-потоки и Android TTS при новом ответе/остановке; гонок не найдено (по коду, без устройства).
- Сценарии: один глобальный захват `CortexActionState.acquire` исключает параллельный и двойной запуск; автоматического повтора после сбоя нет.
