## Что сделано для разных оболочек (PR #100)

- Системные приложения открываются по стандартным ролям Android (`APP_GALLERY`, `APP_MESSAGING`, `APP_CONTACTS`, `APP_CALENDAR`, `APP_EMAIL`, `APP_MAPS`, `APP_MUSIC`, `APP_BROWSER`, `APP_FILES`, `ACTION_DIAL`, `SHOW_ALARMS`, `ACTION_SETTINGS`), а не по подписи иконки. Это не зависит от названия на One UI / HyperOS / Funtouch / ColorOS / MagicOS / Pixel и от падежа («открой галерею»).
- Яркость командой: поддержаны диапазоны `screen_brightness` 0..255 / 1023 / 2047 / 4095 и системный максимум.
- «Работа в фоне» в «Доступах Android»: системное исключение из оптимизации батареи, затем экран автозапуска производителя (Xiaomi/Redmi/POCO, vivo/iQOO, OPPO/realme/OnePlus, Huawei, HONOR, Samsung) — только если этот экран реально существует на телефоне; иначе — настройки приложения.
- Калькулятор знакомства: добавлены пакеты OnePlus, Tecno/Infinix/itel (Transsion), Meizu к уже имеющимся Samsung, Google, AOSP, Xiaomi, Huawei, HONOR, OPPO/ColorOS, ASUS, vivo/iQOO.

## Ручная проверка для тестеров (по каждой оболочке)

Записывать: производитель, модель, версия Android, версия оболочки, версия CORTEX.

1. «Открой галерею», «открой контакты», «открой сообщения», «открой часы», «открой проводник/файлы», «открой календарь» — открылось нужное системное приложение.
2. «Сделай яркость 30 процентов», затем «увеличь яркость» — ползунок в шторке реально изменился, ответ CORTEX совпадает.
3. Доступы Android → «Работа в фоне» → открылся системный экран; после разрешения строка показывает «Разрешено».
4. Свернуть CORTEX, выключить экран на 15 минут, включить: островок и голосовой вызов по имени живы; напоминание через 10 минут пришло.
5. Знакомство: калькулятор найден, 4 вычисления подтверждены, яркость вернулась к исходной.

| Оболочка | Ожидаемые особенности | Статус |
|---|---|---|
| Samsung One UI | калькулятор `popupcalculator`, батарея в «Обслуживание устройства» | не проверено |
| Xiaomi HyperOS / MIUI | диапазон яркости > 255, автозапуск в «Безопасности» | не проверено |
| vivo Funtouch / OriginOS, iQOO | автозапуск в i Manager, свой калькулятор | не проверено (есть жалоба на яркость/калькулятор до этих правок) |
| OPPO ColorOS / realme UI / OnePlus OxygenOS | safecenter автозапуска, `com.coloros/oplus.calculator` | не проверено |
| HONOR MagicOS / Huawei EMUI | systemmanager автозапуска | не проверено |
| Google Pixel / Motorola / Nothing | только системная оптимизация батареи | не проверено |
| Без Google Play Services | Play Integrity недоступен (не используется) | не проверено |
| Android 8–9 | нет `APP_FILES` (API 29) — «файлы» открывается по подписи или не находится | не проверено |
