## 2026-11-18 · Android 1.0.15

- Ветка `fix/cortex-island-version-and-actions`. Базовый коммит `c250c1ad8946f62f4b3e8d39c7d9b3cdce0dcee7`.
- Android 13+ держит размеры окна островка постоянными во время анимации. Область касания меняется отдельно с учётом лимита прозрачности Android.
- Движок уточняет мессенджер на русском и сохраняет получателя и текст. Перед отправкой показывает найденный чат и запрашивает подтверждение. Добавлены локальные команды плеера и кнопки в островке.
- В админке вводится включительный номер заблокированной версии. Используется существующая проверка кода Android. Клиент сохраняет последнее подтверждённое состояние для своего кода версии, а чат показывает отдельную карточку ошибки сети.
- Тесты покрытия находятся в `qa/island-surface-motion.test.mjs`, `qa/chat-beta-polish.test.mjs`, `cortex-control/tests/control-hardening.test.js` и `app/src/test/java/app/cortex/assistant/VisualPlanTest.kt`. Статус сборки Android указан в проверках PR.
- Следующий шаг — проверить островок на Samsung A23 с разными положениями камеры, проверить касания вокруг капсулы и пройти отправку тестового сообщения с отказом и подтверждением. Проверить медиа-паузы с доступом к уведомлениям и без него.
- Supabase и правила на production в рамках этой работы не менялись. Порог и техработы следует проверять на тестовом контуре. Устройство без сети применяет только сохранённую политику.

## 2026-11-18 · Исправления Android 1.0.16

- Ветка `fix/cortex-verified-actions-116` основана на сборке 1.0.15 из PR #65, коммит `03ab69656001aff8856fadcba58ca649504a3398`.
- Островок переключается между двумя фиксированными формами через прозрачность. Окно на Android 13+ размещается в точных локальных координатах; запуск команды больше не раскрывает и сразу не сворачивает панель.
- Запуск приложений ждёт окно до 12 секунд и завершается при первом подтверждении. Ввод проверяется на свежем дереве. Поиск по приложениям идет локально, сторонние чаты выбираются с учетом секций и составных подписей. Для текстовых слоев есть локальное OCR. Отправка требует подтверждения открытого чата и появления сообщения.
- Учи.ру открывается явным URL в выбранном браузере до обращения к ИИ. Общий планировщик показывает подтвержденные действия без использования утверждений модели об успехе.
- Тесты дополняют `VisualPlanTest.kt` и `qa/island-surface-motion.test.mjs`. После CI проверить на Samsung реальные переходы островка, чат с составной подписью, долгий запуск и поиск в разных приложениях.
- Изменений в production или Supabase нет.

## 2026-11-18 · Android 1.0.17

- Ветка `fix/cortex-glass-voice-117` основана на PR #66, коммит `0c615d9115705ba70f0253068a420f3c49f01887`. Включает исправления островка, поиска и подтверждения действий из 1.0.16.
- Полупрозрачный материал островка имеет настраиваемый оттенок. Пять сценок персонажа показываются на свёрнутом островке со стандартным интервалом минимум 180 секунд. Сцены можно отключить, системное сокращение анимаций учитывается.
- Вызов разрешает отдельно отключать озвучку. Встроен прослушиваемый пример и кнопка чтения ответов. Используется существующий шлюз речи, а debug-сборка использует синтез Android. Серверные настройки не изменялись.
- Фонарик вызывает CameraManager и ждёт состояния вспышки. Открытие системной шторки работает отдельным глобальным действием Android. Нажатия по известным плиткам выполняются в визуальном режиме с проверкой нового состояния.
- Задача публикации от 18.11 собрала debug и упала с HTTP 429 при разрешении зависимостей release lint. Workflow проверяет release до подписания и повторяет скачивание при временных сбоях Maven. Проверка постоянного сертификата сохранена.
- Тесты в `VisualPlanTest.kt`, `qa/island-surface-motion.test.mjs` и проверках PR. На Samsung проверить сценки после простоя, «Проверить голос», команды фонарика и плиток. Устанавливаемый артефакт и состояние подписанного релиза указываются по результатам CI.
